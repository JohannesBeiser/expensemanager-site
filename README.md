# expensemanager-site

The website for **Personal-Finances**, a personal ledger for expenses, trips and income.
Three static pages, no build step, no dependencies, **and no images at all**:

| | |
|---|---|
| `index.html` | what the app is |
| `privacy.html` | the privacy policy — **required by App Store Connect** |
| `support.html` | the support page — **required by App Store Connect** |

Served by GitHub Pages from `main`, at the root. Editing a file and pushing publishes it.

There are deliberately no screenshots. They were a synthetic ledger rather than real data, but a
demo built to behave like a real Swiss ledger — a 13th salary, a rent increase, CHF, the same
shops — reads as somebody's actual finances whether or not it is, and this page does not need
pictures to say what the app does. The colours are the app's own: the charcoal is its icon
background, the accents are category colours out of the ledger.
